# The Link Shortener

Этот проект представляет собой высокопроизводительный сервис для сокращения ссылок, написанный на Go.

## Требования

- Go 1.22+
- Docker и Docker Compose
- PostgreSQL

## Настройка

1. Склонируйте репозиторий:

```bash
git clone https://github.com
cd The-link-shortener-on-Golang
```

2. Создайте файл `.env` из примера:

```bash
make env
```

3. Настройте переменные окружения в созданном файле `.env` (например, параметры подключения к БД и порты).

## Запуск

### Быстрый запуск через Docker
Развернуть всю инфраструктуру (приложение, базу данных PostgreSQL и Redis) одной командой:
```bash
docker-compose up -d
```

### Локальный запуск (для разработки)
1. Запустите инфраструктуру базы данных:
```bash
docker-compose up -d
```
2. Примените миграции для создания необходимых таблиц:
```bash
make migrate-up
```
3. Запустите сервер локально:
```bash
make run
```

## Команды

В проекте доступны следующие команды через `Makefile`:

##### `make build`: Сборка проекта
##### `make run`: Локальный запуск сервера
##### `make test`: Запуск тестов
##### `make clean`: Очистка бинарных файлов
##### `make lint`: Запуск статического анализатора кода golangci-lint
##### `make migrate-up`: Применение миграций базы данных PostgreSQL
##### `make migrate-down`: Откат миграций базы данных PostgreSQL
##### `make env`: Создание файла .env на основе .envexample
##### `make help`: Вывод подсказки по всем доступным командам

## Postman

Для отправки запросов используйте следующие примеры:

```json
{
  "url": "https://google.com",
  "custom_code": "my_custom_alias"
}
```

###### API реализация сокращателя ссылок:

- **Отправка методом POST** с телом запроса выше для создания короткой ссылки:
```bash
http://localhost:8080/shorten
```
*Примечание: Поле `custom_code` является необязательным. Если его не передать, сервер сгенерирует случайный уникальный код из 6 символов.*

- **Отправка методом GET** по короткому коду для редиректа на оригинальный сайт:
```bash
http://localhost:8080/my_custom_alias
```
*Запрос возвращает HTTP-статус `307 Temporary Redirect` и мгновенно перенаправляет пользователя.*

## Swagger

Для наглядной проверки работоспособности сервера и интерактивного тестирования API используйте:

```bash
http://localhost:8080/swagger/index.html
```

---

###### Сервер работает по принципу создания короткой ссылки (со случайным или кастомным кодом), которая сохраняется в базу данных PostgreSQL. При переходе по короткой ссылке (метод GET) приложение выполняет мгновенный редирект пользователя на оригинальный URL, после чего асинхронно отправляет задачу в очередь на Go-каналах (`clickQueue`). Пул из 5 активных горутин-воркеров параллельно разбирает эту очередь и инкрементирует счетчик кликов (`clicks`) для каждой ссылки в базе данных, обеспечивая высокую пропускную способность без блокировки основного HTTP-потока.
